# Knowledge Base for RiskWise Agentic Copilot

This folder contains curated, authoritative domain literature for RAG (Retrieval-Augmented Generation) used by the RiskWise Copilot.

## Rules & Integrity
1. Only public educational guidelines and official regulatory documents may be placed in `sources/`.
2. Every document MUST have a corresponding entry in `manifest.csv`.
3. The Copilot must strictly cite documents registered in `manifest.csv` and never hallucinate citations or page numbers.
